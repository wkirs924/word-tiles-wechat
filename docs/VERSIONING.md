# 版本与 Git 保存约定

项目从 2026-09-29 起使用独立 Git 仓库保存。原始微信预览源码和压缩手机包在同一仓库中分别保留：

- `apps/wechat-preview/`：完整源码与浏览器预览包。
- `apps/wechat-phone-preview/`：压缩后的微信手机预览包，当前用于上传的版本为 `1.0.4`。

提交信息统一使用：

```text
codex-YYYYMMDD-NN-vX.Y.Z: 简短变更说明
```

其中 `NN` 是当天的顺序号，`X.Y.Z` 与微信上传版本对应。每个可交付版本同时创建同名的 Git 标签 `vX.Y.Z`，方便回退和比较。临时构建目录（`.tmp/`）、依赖和本地缓存不纳入仓库。
