# 手机端字麻将 · Codex 云端开发

本仓库保存微信工程，主要界面源码入口为 `apps/wechat-preview/game.js`。完整工程包含规则核心、服务端、素材、构建脚本与测试；`apps/wechat-phone-preview` 为微信上传包的构建产物。

## 环境与验证

使用 Node.js 24 或更新版本、Python 3。现有 Node 测试不需要安装 npm 依赖。

```sh
node --version
python3 scripts/build-wechat-phone-preview.py
npm test
```

`project.private.config.json` 是本机微信工具配置，不上传。手机包构建在该文件缺失时使用已验证的基础库版本 `3.17.3`。原始 GIF 的重新生成仍依赖本机外部素材目录；云端可使用仓库中已有的动画图集，不能声称原始 GIF 已在云端重建。

云端修改后提交代码或创建 PR，再由电脑拉取并在微信开发者工具、真实手机上验证。云端不能替代微信登录、预览上传或双手机真机验收。

## 手机查看结果

先在 ChatGPT 网页或 Codex 桌面创建并发布本仓库的云端环境。手机 ChatGPT 打开 Codex，选择该环境；打开同一个任务可以查看总结、测试与代码改动。普通聊天不会自动接收其他云端任务的消息。
