# 游戏界面与资源共用约定

## 统一基准

“四人试玩”的横屏界面是今后开发的设计基准。联机房开局、骰子选主家、牌桌、表情造句、投票、评分和结算应呈现相同布局、边框、字牌比例、按钮位置与操作顺序。改界面时同时检查本地试玩和联机入口，不能只修其中一个。

## 共用实现

- 牌桌、骰子和面板优先调用同一绘制函数。联机只提供当前玩家可见的视图以及提交命令的回调；本地试玩提供本地规则视图和操作回调。
- 字牌、牌背、头像、桌面、表情封面与动图共用 `apps/wechat-preview/assets/` 和 `content.js` 清单，不为联机另复制一套素材。
- 字体、颜色、间距、滚动、已选表情排序和动图交互采用同一规则；确有模式专属信息（房间号、准备状态、双座位切换）只在对应位置补充，不改变共用画面结构。
- 动图点按一次后循环播放，切换到其他动图时只保留当前活动图集；滑出可见范围暂停重绘，返回时继续，进入后台暂停，回到前台恢复。性能或内存告警可释放图集。
- 用户相册表情复用同一表情选择、搜索、投票、评分和轮播画面。私有收藏与房间共享只影响资源来源和可用状态，不能另做联机表情界面；元数据、字节同步和磁盘存储放在适配模块中。当前实现和范围见 `CUSTOM_MEMES.md`。

## 修改与生成

界面源码是 `apps/wechat-preview/game.js`，动画编码参数是 `scripts/animation_assets.py`。先修改源码；改动画图集时运行 `scripts/build-preview-content.py --animations-only`，然后运行 `scripts/build-wechat-phone-preview.py` 生成手机包。不要直接修改 `apps/wechat-phone-preview` 内的生成代码、素材或 `content.js`。后续 Cocos 正式端参照这套界面，不另定一套布局。
