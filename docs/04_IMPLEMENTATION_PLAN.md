# 开发规划与任务清单

阶段按依赖执行，估算天数仅作排期参考。每阶段产物先测试再推进；缺少平台凭据只阻塞对应平台验收。

| 阶段 | 任务 | 产物 | 退出条件 |
|---|---|---|---|
| M0 交接 | 规则快照、结构、契约、bootstrap | 本交接工程 | 初始测试可跑，未完成项可追踪 |
| M1 规则 | 完整单局、会话、投影、回放、对照样本 | packages/core + tests + M1_REPORT | 核心行为与旧版对照，隐私/幂等/计分通过 |
| M2 联网 | 身份、房间、串行裁决、事务、四客户端、恢复 | apps/server + 网络集成测试 | 四客户端完整局，崩溃恢复与重试不重复结算 |
| M3 客户端 | Cocos 工程、横屏 UI、意图控制器、浏览器适配 | apps/client-cocos | 手机尺寸预览全流程；四客户端连接 M2 |
| M4 微信 | 平台适配、登录分享、构建、双端实测 | 构建配置与设备记录 | 开发者工具可构建，Android/iOS 真机完整局 |
| M5 内测 | 动图、缓存、性能、连续对局、运行手册 | 内测包、诊断与交付记录 | 质量预算实测、长局不增长、恢复矩阵通过 |

## M1：规则等价

- C01 JSON 边界/规范化/安全字典，拒绝未知字段和非有限数。
- C02 默认配置与可选配置校验、确定性洗牌、骰子和逐人发牌。
- C03 摸打、提案、投票、原子结算与终态。
- C04 command_id 去重（含失败）、多局历史、精确累计、排名、回放。
- C05 白名单玩家投影/事件；未知身份拒绝。
- C06 从 Godot 生成固定输入输出样本；对照 TS 状态/事件/回执/视图。
- C07 将旧测试的边界逐项映射到新测试名，标记未覆盖部分。

先有完整规则再接 UI，不让按钮回调计算分数或推进回合。

## M2：权威房间服务

- S01 运行时请求校验、错误 DTO、请求大小与频率限制。
- S02 房间 4 席、成员身份、ready、重入、开局权限。
- S03 单房间串行队列、同一投票阶段并发三票、幂等键隔离。
- S04 事务存储状态和回执；写失败回滚；启动加载活动房间。
- S05 每连接只发送其视图；重连替换旧连接，恢复完整快照。
- S06 房间内容版本冻结；网络禁传种子/牌墙；服务器显式随机牌墙。
- S07 四个自动化客户端完成整局与下一局；停止服务后恢复。
- S08 日志含 room/command/revision/耗时，默认不含 token/完整手牌/私有票。

## M3：手机客户端

- U01 检测/锁定编辑器版本，创建真实可打开的 Cocos 工程与入口场景。
- U02 PlatformPort：浏览器/微信隔离；TransportPort：本地/网络隔离。
- U03 菜单、房间、准备、牌桌、选图、投票、结算、重连遮罩。
- U04 草稿只含本地选牌/选图/评分；服务端快照为最终事实。
- U05 触摸排序、滚动手牌、中文搜索键盘、安全区、按钮防连点。
- U06 两套字库；先小素材库；资源错误不阻塞牌局状态同步。
- U07 generated 共享模块构建脚本，避免 core/protocol 重复维护。

## M4：微信集成

- W01 AppID/开发者工具/编辑器检查；不提交凭据。
- W02 `wx.login` → 服务端会话、分享房间信息、前后台恢复。
- W03 HTTPS/WSS 与合法域名配置说明、开发和生产配置分离。
- W04 包体报告、分包/远程资源、冷启动和失败重试。
- W05 Android/iOS 真机各完成一局；记录系统、微信、基础库和设备型号。

AppID 未提供时可以完成适配接口、mock 集成、构建准备与文档，但 W02/W05 标记待验证。

## M5：资源及稳定性

- A01 离线素材处理清单：key→预览→优化动画→哈希；不打入原始帧图。
- A02 按需加载、下载去重、LRU、引用计数、取消过时请求和释放纹理。
- A03 弱网、断网、切后台、杀进程、素材版本不匹配的恢复提示。
- A04 连续十局或 30 分钟测试，记录峰值内存及释放后基线。
- A05 README 运行指南、部署模板、已知问题、测试证据与剩余依赖。

## 每阶段交付格式

报告包含：实现了什么；改动文件；测试命令/实际结果；未实现/未验证；下一阶段首个可执行任务。不得只写“基础完成”“基本没问题”。
