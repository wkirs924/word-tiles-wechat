# 总体规划

## 产品目标

四人通过微信邀请或房间码加入好友房。四人准备后开局，按当前字牌规则摸打、造句、附表情、互相判断与评分，完成本局和累计排名。第一版横屏，保留原项目牌桌辨识度；文字与触摸目标按手机重新排版。

## 首版范围

- 微信身份登录、建房/入房、四席准备、邀请、退出/解散。
- 每人只看自己的手牌；其他人仅显示牌数及公开信息。
- 136 张字牌，庄家 14、其余 13；每局打空手牌或牌墙耗尽后独立结算，下一局由房主选择是否再开。
- 两字起出句；可不带表情，带图最多 12 个且顺序有意义。
- 其他三人投认可/反对；带图再选 0–3 分，无图直接提交 rating=0。
- 三票齐后一次结算；两票以上认可通过，否则本手零分并强制弃一张。
- 通过后手牌空则胡，牌墙耗尽在下一次应摸牌时流局。
- 每局精确计分、并列排名；历史局可累计记录，但不要求连续打满多局才分胜负。支持断线恢复、切后台恢复。
- 固定素材集、搜索、缩略图、选图顺序、静态降级。

暂不做：陌生人匹配、观战、聊天、语音、玩家上传、广告、内购、全服排行榜、复杂机器人、Steam 功能。原 PC 素材工作台继续用作离线制作工具，不直接暴露到公网。

## 用户流程

启动/恢复 → 登录 → 建房/入房 → 房间四席准备 → 选定主题与内容版本 → 服务端开局 → 摸打/出句 → 其余三人投票 → 继续/结算 → 下一局/离开。

断线不自动代打、不自动判负、不默认赞成。保留既有等待/房主结束方式；房主退出或全部离线的清理策略见决策文档。任何引入计时投票或 AI 代打的改动均作为新规则版本处理。

## 交付层次

1. 规则等价：命令输入下结果、事件与私有视图可对照。
2. 本地联网：四个客户端连接同一权威服务，完整对局及恢复。
3. 手机操作：Cocos 界面完整可玩，字牌和按钮可点、排序不误触。
4. 微信运行：真实开发者工具构建与双端真机证据。
5. 内测稳定：连续对局、资源性能、失败提示与诊断齐备。

“完成前三层”不能写作“微信版已经交付”。

## 工期使用方式

此前 5–8 天可玩、10–14 天打磨是粗估，不能替代阶段验收。每阶段结束基于实际环境与失败项更新剩余工作；不为赶天数删掉隐私、幂等或恢复测试。
