## 试玩

主菜单提供 **NBA** 与 **英雄联盟** 两套字库，均为 68 种字各两张、合计 136 张；NBA 表情图片和原有主目录／lol 表情均可在回合内选择。相近情绪的图片使用统一搜索关键词，素材网页仍可编辑字牌与关键词，以及导入／导出带图片的整包。字牌取舍见 [NBA 字库](docs/BASKETBALL_PACK.md) 和 [英雄联盟字库](docs/LOL_DECK.md)。

1. 双击 PLAY.cmd（Godot 4）；同一设备轮流控制四席，通过交接屏切换玩家。
2. 发牌后庄家直接行动，其余回合先摸一张；两字起出句。
3. 点击手牌会自动展开上方的表情面板。直接点图片选择或取消（可不选图；多选默认最多 12 张，按点击顺序），上方字块可拖动修改字序，已选图片可拖动或用左右箭头换序；再点「出牌」连同句子一次提交。
4. 每图展示关键词；搜索按名称或关键词过滤。选择字牌后，匹配不同字越多的图片越靠前。“开心”匹配“开”和“心”；重复字不重复加权，候选排序不改变已选图片顺序。
5. 其他三位交接后先点认可或反对；有表情则转场到评分页，点击分数一起提交，可返回修改判断；无表情直接提交。三票全收齐才结算；否决整手零分并强制弃一张，通过的平均分逐次累计。
6. 胡牌/流局直接查看本局和累计排名，主机可开下一局。M5 联机未实现，单人可轮流操作四席测试。

## 修改素材

双击 EDIT_MATERIALS.cmd，在工作台里改素材与外观，保存后回游戏“重载素材”。不需要改代码。七个标签页：

- **素材映射**：图片路径、上传替换、名称、用途、授权备注。
- **表情包**：图片、名称、资源 key、关键词、上传替换与搜索。
- **界面文案**：按游戏页面分组（主菜单/交接/牌桌/表情面板/投票/结算/提示错误等），每 key 保留不变。
- **主题颜色**：面板、纸色、文字、强调色和表情轮播秒数。
- **字体**：默认字体链 + 基础字号，并可给「选项/按钮」「投票页」「结算得分」「牌面汉字」四个用途单独指定字体。
- **试玩字库**：逐行改字和张数，总数必须恰好 136，下局生效。
- 使用与替换指南：上传、导入导出草稿和素材包的说明。

每张表情至少一个非空关键词，多个用逗号分隔。字体只接受系统已安装字体名，保存并重载后生效。字库仍须恰好 136 张。

## 测试

完整回归：`powershell -ExecutionPolicy Bypass -File scripts/test.ps1`，内部执行 tests/run_tests.gd，检查退出码、SCRIPT ERROR 和最终失败数。

纯逻辑/投影/主机/搜索快速入口：`godot_console --headless --path . --script res://tests/run_logic_tests.gd`。

素材服务：`python tools/content_editor/test_server.py`。

只改表现层时的快速回归：`godot_console --headless --path . --script res://tests/run_ui_tests.gd`。提交前仍需完整回归。

素材映射、文案分组、模块边界与文档链接：`python -m unittest discover -s tests -p test_project_integrity.py`。

渲染检查：`godot_console --path . --script res://tests/capture_preview.gd`，输出 .local/preview。它是自动脚本截图，不代替鼠标人工试玩。

本机 Godot 为 C:/Users/cyr/bin/godot_console.exe；Python 可用项目启动器自动查找的运行时。其他电脑需 Godot 4、Python 3.10+。PLAY.cmd 是项目启动器，并非导出的独立 exe。
