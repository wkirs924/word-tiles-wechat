# 2026-09-25 · UI 与交互动效交接

## 本轮成品
深墨绿与暖金视觉：背景、牌桌描边、按钮状态、输入框、滚动条、焦点环统一。保留原有四方麻将桌布局、所有字库和用户表情关键词。

- 选牌抬起、取消落回；首次手牌展开与摸牌从中央入手；自己的弃牌沿同一个物理牌 ID 移至公开牌河。
- 候选表情依旧按关键词匹配排序，但位置变化平滑移动；新筛出的项目淡入。
- 已选图片有独立有序栏，可以拖动换位、点前后箭头或移除；编号随顺序刷新。
- 句子草稿是一行紧凑字块，可以拖动修改字序；Tab 聚焦后左右键调整。手牌原有顺序不变，提交使用草稿顺序。
- 表情面板可收起，通过“表情造句”重新展开；不会清空已有选择。
- 左图右投票，0–3 评分与认可/反对都直接可见；轮播有淡入。句子文本不再重复飘字遮挡标题。
- 结算采用对齐表格与排名卡片，下一局按钮可见。
- 菜单/交接/浮层入场、按钮悬停/按压、分数提示有过渡；动效可以简化，排布和浮字可以立即跳过。

## UI 开发硬约束
1. reducer 与投影是唯一规则依据。本轮没有修改 core、application、projection；动画完成不发命令，不等待动画推进回合。
2. 动效只保存控件标识、位置、透明度和 Tween。换人立即移除旧手牌节点，不用旧手牌截图或退出动画延迟遮挡。
3. 牌桌使用 1280×720 逻辑画布，适配窗口；本轮检查 1280×800 和 1000×700。桌边座位、底部手牌与操作区各有固定范围，浮层不覆盖出牌按钮。
4. 表情卡片等高，图片先设置缩放模式再赋纹理，长文案省略并提供悬停信息；滚动只发生在候选区/顺序栏/超长投票内容。
5. 排序按稳定 key 配对旧位置与新位置，常规过渡 0.28 秒，悬停 0.12 秒，轮播淡入 0.22 秒。快速输入会取消上一批排布动画，只追赶最新布局。
6. “跳过动画”取消尚未开始的排布任务并恢复终点；简化动效不影响可操作性。轮播本身用播放器暂停按钮控制。
7. 拖动只改草稿。无效索引、未知项目与跨组拖动不能篡改顺序；没有新增规则分支或客户端计分。
8. 复用现有字体角色和素材映射。新文案仍在 catalog.ui；颜色在 catalog.theme。布局尺寸属于表现代码，不混进核心配置。
