## 牌与回合

四人，默认 136 张独立物理 ID 的汉字牌。宿主提供字库和显式种子，或完整牌墙与骰子；核心不读时间、不使用全局随机。默认两枚六面骰，庄家座位为 `(参考座位 + 点数和 - 1) mod 4`。从庄家开始逐人发 13 张，庄家额外一张且先行动、不摸牌。

其余回合先摸一张，再弃单张或提交至少两张的句子。句子文字由所选物理牌顺序生成；可记录各位置的 null 或 tone 1–4，不允许替换文字或音节。仅出句通过且手牌为空会胡牌；单张弃牌不触发胡牌。剩一张可下回合摸成两张再出句。

牌墙最后一张摸出后仍完成行动及投票；下一次需要摸牌且牌墙已空才流局。胡牌和流局都在同一次命令中直接清算，不再等待任何局末素材操作。

## 回合内表情造句

点击手牌会自动展开表情面板，不提交命令、不消耗行动。可不选图片；也可选最多 config.max_meme_images 张（默认 12，配置范围 1–100），同 key 不重复。点图片选择或取消，图片按点击顺序保存；取消后重新加入排在末尾；提交前可在有序栏拖动或用箭头修改顺序。字牌草稿同样可拖动调整，提交后不能改序。点“出牌”连同已选图片一次提交。

提交句子同时提交有序 resource_keys。出句后图片与句子对全部参与者公开；投票前牌仍留在出牌者手中。候选排序不改变已选图片顺序。

每图至少一个非空关键词，可在素材映射网页编辑。搜索先按名称/关键词包含匹配过滤，再按匹配到的不同选中字排序。关键词“开心”匹配“开”或“心”，两字都选中计 2；重复字牌、重复关键词不重复加权。同分保持素材表顺序；无匹配仍可显示。取消选字立即重排。不做拼音、谐音、近义词推断。搜索排序只属于表现层。

## 原子投票与评分

出牌者以外三人，每人一次提交 approve（布尔）和 rating（默认整数 0–3）。必须都填写；不能自评、改票或只提交其中一项。不同命令重复投票拒绝，同 command_id 重发返回原回执。

三份全部收齐后才判断，至少两票认可通过。投票过程中只公布数量和本人是否已投，不公布任何人的选项、分数或实时平均分。最终只公布总认可数与通过句子的平均分，不公布逐人明细。

当前补足边界：沿用“否决整手 0 分”；无图句子不评分，命令 rating 固定为 0，评分加分为 0；带图句子才参与评分。通过时包含全部三人的评分，即使其中一人投反对。否决不计任何分，牌不移出，必须再弃一张；庄家首回合也一样。若用户以后改动这两个默认边界，先更新本文件、核心和测试。

## 分数

通过句子的字数分 = 字数 + 字数奖励：2–3 字额外 0，4–5 字额外 1，6 字起额外 3。

每次通过句子的额外评分 = 三人分数之和 / 3。一个玩家的多次通过句子分别取平均后相加，不是对全局所有评分再取一次平均。

本局总分 = 所有通过句子的字数分之和 + 所有通过句子的平均分之和 − 剩余手牌数。

例如两次通过，字数分分别 2、5，评分和分别 5、3，剩两张：总分为 7 + 8/3 − 2 = 23/3。state.scores 保存整数的字数分，rating_bonus_thirds 保存累计评分和；最终分数与跨局总分用分母 3 的精确数值，排名不先舍入。界面两位小数只用于显示。

## 会话与中途结束

默认四局，可由主机显式继续额外局；每局新 ID、新随机输入、重新洗全副牌并定庄发牌。跨局累加精确分子；累计同分并列，显示名次 1、2、2、4，座位不作破同分条件。

END_GAME 仅可信主机可调用。取消尚未完成的提案和部分票，不额外移牌，不回滚已成功摸牌。已通过的句子、图片、字数分及评分加分保留；HOST_ABORT 不生成最终分，不加入累计，不消耗计划内完成局数。胡牌和清算现为一个原子步骤，不存在“胡牌后等待评分”的中间阶段。COMPLETED/ABORTED 是终态。

掉线不代打、不判负，主机选择等待或结束；重连从主机重新取得投影。核心不设置时间或超时。
