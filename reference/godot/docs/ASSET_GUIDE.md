# 素材工作台：文件、网页与游戏对应关系

所有路径相对于这一份 `word_tiles_m3_m4` 工程。网页顶端显示实际项目绝对路径，请先确认，避免编辑另一份副本。默认网页地址为 http://127.0.0.1:8765；先运行 EDIT_MATERIALS.cmd，它不是联网网站，也不会上传你的素材。

篮球表情、NBA 字库和可导入素材包见 [BASKETBALL_PACK.md](BASKETBALL_PACK.md)；另一套预设见 [LOL_DECK.md](LOL_DECK.md)。

## 最常用的两种替换方式

**在网页换图：** 打开“素材映射”，找到目标行，点“上传替换”选择自己的 SVG/PNG/JPG/WebP → 页面显示新图和新的 assets/imported 路径 → 填写名称、关键词、授权说明 → 点顶端“保存到项目” → 游戏点“重载素材”。上传文件已落盘，映射须保存才生效。保留原 key，正在使用该 key 的界面也会更新。

**在文件夹换图：** 将新图片放进 assets/ui、assets/memes 或 assets/imported，然后在网页修改该行“文件路径”，保存并重载。也可以直接覆盖原文件（扩展名和实际格式要一致），不改 key 和路径，只需游戏重载。建议先自行保留原图片副本；网页自动备份的是 JSON 表格，不是图片文件。

单张上传上限 8 MB。推荐背景 1600×1000、牌底 120×160、表情包 640×480。尺寸是推荐值，游戏会缩放；纵横比不同可能出现留白或裁剪。SVG 必须为静态矢量，禁止脚本、外链、嵌入 HTML 与 style 属性；遇到不兼容的 SVG 可导出 PNG。

## 网页表格各字段

| 字段 | 用途与修改效果 |
|---|---|
| 显示名称 title | 表情包选择界面标题，也是关键词筛选范围 |
| 资源 key | 游戏状态里引用的稳定标识，不是路径。八个固定 UI key 不可改。已有历史使用的表情包 key 建议一直保留 |
| 文件路径 path | 相对项目的 assets/ 路径；不能填盘符、绝对路径或网页地址 |
| 出现位置 usage | 给维护者看的用途说明，不参与规则 |
| 建议尺寸 size_hint | 人工维护的建议，不会自动改变游戏布局 |
| 关键词 keywords | 用中文或英文逗号分隔；每图至少一个非空词；游戏按名称和关键词搜索，再按选中字在关键词内的不同字符匹配数排序。例如“开心”同时匹配开与心，重复字不重复加权 |
| 来源/授权 license | 记录作者、授权类型和凭证位置；填写此字段不等于取得授权 |
| 替换说明 notes | 保留替换注意事项、版本说明等 |

“＋ 新增表情包”会复制一个模板行并生成新 key；也可以在「表情包」页用卡片视图管理（只显示图片、上传替换和关键词，点击更少）。上传自己的图、填名称和关键词、保存重载后即可选择。“移除映射”只删除表格行，保留图片文件；必须保留至少一个表情包。正在对局或要保留历史可见效果时不要移除已使用的 key。缺失图片会显示提示，已确认的得分保持不变。

## 文案、颜色、字体和字库

- “界面文案”按游戏页面分组（主菜单、交接页、牌桌对局页、表情造句面板、表情轮播、投票页、结算页、系统提示与错误），可以按 key 或文字搜索并直接修改右侧文字；保留 key。暂不支持在网页改变布局、牌大小或动画参数。
- “主题颜色”控制面板、纸色、文字、强调和背景补色；背景图片不跟随主题自动变色。muted 控制牌桌下方操作提示的颜色。
- “字体”设置默认字体链（第一项是主字体，找不到时依次用备选）和基础字号，并能给四个用途单独指定字体：选项/按钮、投票页、结算得分、牌面汉字；留「跟随默认」即用默认链。只接受系统已安装字体的系统名（如 Microsoft YaHei、SimHei、KaiTi），不能上传字体文件。保存后回游戏「重载素材」生效。
- 评分按钮和结算表的电子数字由 `digital_number.gd` 绘制；网页的系统字体设置只影响对应文字，电子数字颜色在「主题颜色 → 电子数字发光色」修改。
- “试玩字库”逐行填一个字和整数张数，可增删行，但总数必须恰好 136。主菜单当前只有 NBA 和英雄联盟两个预设，均为 68 字各 2 张；另外保留的初始 34 字各 4 张是编辑器的后备试玩数据。核心不负责判断某字是否适合组句。
- 新字库在游戏“重载素材”后，从下一局发牌时使用。已发到手中的牌和过去通过的句子不会改变。
- 同一会话的规则配置仍来自 core/rules.gd。网页不能修改计分、投票和胜负规则，不存在两份计分实现。

## 保存、备份与冲突

| 文件/目录 | 内容 |
|---|---|
| content/catalog.json | 游戏实际读取的素材表、文案、颜色、字体和试玩字库 |
| content/catalog.previous.json | 每次网页保存前的上一版表格，只保留一版；不进入 Git 包 |
| assets/imported/ | 网页上传的新文件，文件名前加随机标识，避免覆盖原图 |
| .local/editor.stdout.log / editor.stderr.log | 素材服务运行日志，不进入 Git |
| .local/game.log | 试玩日志，不进入 Git |
| tools/content_editor/index.html / editor.js / style.css | 网页本身；一般换素材不需要编辑这些文件 |

“导出草稿”下载当前未保存配置。使用指南底部可以导入草稿，导入之后仍须点保存；图片文件需要随工程一起复制。两个网页同时编辑时，旧版本保存会被拒绝，先导出草稿再重新载入并合并修改，不能覆盖别人已保存的修改。手工编辑 JSON 前先导出或复制备份，编辑完再从网页重新载入，避免使用旧页面覆盖手工结果。

恢复上一版：先复制 catalog.previous.json 留档，再将其内容复制到 catalog.json，重新载入网页并重载游戏。配置文件损坏时游戏拒绝替换已加载的可用配置。系统并不提供任意版本历史；重要版本请另存项目副本或提交 Git。

## 启动与关闭

双击 PLAY.cmd / EDIT_MATERIALS.cmd。如果另一份工程占用了 8765，启动器会拒绝连接错误的工程；先在那份工程运行 scripts/stop_editor.ps1。停止当前服务也使用该脚本，游戏不依赖服务常驻。

其他电脑需要 Godot 4 和 Python 3.10+；可分别给 scripts/play.ps1 的 `-Godot`、scripts/start_editor.ps1 的 `-Python` 参数指定程序。本机启动器优先检测已有 Codex Python，再检测 PATH 中的 python。网页没有 npm 或第三方 Python 包依赖。

## 以后接入的内容

本版无语音、声调选择 UI 或音频编辑，接入时再增加音频目录。没有互联网图片搜索、持久化表情包数据库、Steam 创意工坊、审核后台或多端同步。当前自制占位图不引用外部 IP；换成第三方图片或音色时需自行核实商用与再分发授权。资源 key 隔离文件路径，不能免除版权责任。正式 UGC 发布要另建审核、举报、屏蔽和下架流程。

固定界面素材的唯一清单位于 content/ui_contract.json，游戏与素材服务共用，网页由服务取得这份清单。普通换图只修改 catalog.json，不能删除固定 key；可修改文件路径、名称和说明。

多选轮播：点击图片选择或取消，随“出牌”连同句子一起提交。投票页显示当前序号，支持自动播放、暂停和手动切换。网页“主题颜色”页可修改播放间隔，对应 catalog.json 的 playback.seconds_per_image（0.25–30，默认 2 秒）；它不进入规则状态。
