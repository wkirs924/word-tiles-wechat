# 英雄联盟字库：68 种字、136 张牌

主菜单的“英雄联盟”预设位于 `content/catalog.json` 的 `lol.words`。下列 **68 个不同汉字各有两张**；洗牌由主机执行，配置中的先后顺序不决定摸牌顺序。

> 丢 脸 僵 尸 不 是 人 吃 饭 哭 伤 心 戏 喝 水 吓 开 高 兴 想 法 耍 打 击 掏 裆 摔 倒 气 笑 了 害 羞 跳 舞 关 门 冲 变 色 坐 牢 伙 伴 眼 小 虎 鄙 视 憋 量 抽 烟 团 挡 路 神 绑 架 奖 杯 超 强 天 哥 情 侣 生

这次先将相近情绪的图片统一标注，再选字。高兴类图片共用“开心／高兴”，生气类共用“生气／愤怒”，哭伤类共用“哭泣／伤心”；图片独有的动作、人物和梗仍保留。本套字牌现在能完整拼出“开心”和“高兴”两个常用同义词。素材网页的搜索仍会匹配图片标题；删除某个关键词不代表删除图片。

为给“高、兴”腾出两种字，字库去掉了“痛、苦”。`meme.gs.019` 的画面里人物在笑，因此补了可见动作标签“笑”；这张图片仍可由牌匹配，标题中的“回忆、痛苦”也保持不变。

按当前素材映射统计：主目录及 lol 的 **50/50 张**表情均至少有一个能用整副字库拼出的完整关键词；完整关键词标注为 **62/105**。按此前的 119 条示例句子逐字复核，**87 条**仍可由整副字库组成。后一数字只衡量这批示例，不是随机起手的成句率；投票是否通过也不由字库决定。

| 可组成的句子 | 可联想的表情关键词 |
|---|---|
| 小虎跳舞、小虎开心了 | 小虎、跳舞、开心 |
| 小虎生气了、小虎笑了 | 生气、笑 |
| 小虎打团、天哥打团 | 打团、天哥 |
| 僵尸不是人、小虎不是僵尸 | 僵尸、不是人 |
| 小虎是伙伴、超人强打团 | 伙伴、超人强 |
| 小虎跳舞摔倒了 | 跳舞、摔倒 |

这些是整副牌可以组成的示例，不保证同一手牌中同时拿到所需字。用户可在素材网页编辑 `lol.words` 的字与张数，也可改图片的关键词；保存后下次发牌使用新配置。表情候选仍按所选字与关键词的**不同汉字重合数**排序，不做语义判断。
