# 四方麻将桌 UI 更新

按用户提供的麻将游戏截图调整空间布局，使用本项目自制牌桌、背牌和头像，不复制截图里的品牌、人物或麻将牌面。保留汉字出句玩法，不增加吃碰杠或麻将和牌判断。

## 画面与操作

- 当前接手玩家始终在底部，自己的汉字牌横排显示；另外三人依座次位于右、上、左，只展示相应数量的背牌。
- 四家头像名片显示座位、庄家、剩余手牌数、本局已确认出句分；行动玩家有金色边框。
- 点击名片下的“交接到此位”进入遮挡屏，确认后旋转到新玩家视角。当前玩家点击“我的座位”也会先遮挡。
- 轮到自己先点“摸牌”；新摸牌靠右隔开放置并标记“新摸”。选牌上提，选择顺序标为 1、2、3，桌面预览相同顺序的句子。
- 选一张点“出牌”直接弃牌；选至少两张点“出牌”则连同表情面板一次提交句子。按钮是否可用依据投影提示，命令是否合法仍由核心最终验证。
- 出句在桌面中央展示，其他三位交接后投票。投票进度匿名；投票阶段保留自己的手牌显示但禁止选牌行动。
- 牌桌中央显示余牌、当前行动和骰子值。四家弃牌分区显示，每家最多展示最近 24 张，超出数量有提示；“大家认可的句子”窗口可查看完整公开句子及全部牌河。
- 表情面板在点击手牌时自动展开（0.24 秒淡入/缩放/上滑过渡，只在首次展开播放），点图片即可选择或取消，选中显示金框与顺序号；图片与评分随出句投票在桌面中央显示，局末直接结算；仍可通过四周名片交接。按钮、投票、结算和牌面的字体可在素材工作台「字体」页按用途设置。
- 默认窗口 1280×800；桌面按比例缩放，保持座位和手牌相对位置。动画仍然只是提示，不阻塞规则。

## 修改位置

| 文件 | 职责 |
|---|---|
| presentation/mahjong_table.gd | 四方桌面、名片、背牌、牌河、手牌布局和意图信号 |
| presentation/main.gd | 交接、命令提交、最新投影、事件动画与 M4 浮层内容 |
| presentation/meme_player.gd | 按 resource_keys 顺序播放；计时器、暂停和手动翻页全是表现层行为 |
| assets/ui/table.svg | 自制绿色渐变牌桌，可从素材表更换 |
| assets/ui/tile_back.svg | 背牌图片，映射 ui.tile_back |
| assets/ui/avatar_*.svg | 四家头像，资源 key 及替换说明见 ASSET_GUIDE |
| content/catalog.json | 新增背牌、头像映射、桌面提示文案与 font（默认链 + options/vote/score/tile 角色）；规则配置不变 |

桌面组件只接收玩家投影和临时选择，发出 seat_requested、tile_selected、action_requested、vote_requested 信号。它不调用权威主机、不持有他人的牌，也不判断分数和胜负。素材资源通过 ContentStore 解析，界面没有把图片路径写入游戏状态。
